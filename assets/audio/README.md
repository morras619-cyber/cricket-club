# Match ambience audio

Place the supplied `Low level crowd loop.mp3` file in this directory and rename it to:

`low-level-crowd-loop.mp3`

The match audio code loads it from `./assets/audio/low-level-crowd-loop.mp3`, loops it continuously during a match, and plays it at 20% volume. The existing Sound setting controls this ambience.

The MP3 itself still needs to be uploaded here; this connector can edit text files but cannot reliably transfer the conversation's binary audio file into a GitHub commit.
